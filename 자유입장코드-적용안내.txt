자유 입장 코드 + 진행자 비밀번호 제거 수정본

지난번처럼 진행자와 청취자가 같은 코드를 입력하면 같은 방에 들어갑니다.
예: 모두 1234 입력 → 같은 방. 다른 모임이 5678 입력 → 별도 방.
코드는 영문/숫자 1~8자. 앞뒤 공백은 제거하고 영문 대소문자는 구분하지 않습니다.
진행자가 먼저 들어갈 필요는 없습니다. 청취자가 먼저 들어가 방송을 기다릴 수 있습니다.
방마다 음성과 질문 목록이 분리됩니다. 진행자 비밀번호는 사용하지 않습니다.
같은 코드를 행사마다 다시 사용하면 해당 방의 최근 24시간 질문이 보일 수 있습니다.

적용
1. 이 ZIP을 풀고 폴더 안의 파일/폴더 전체를 GitHub 저장소 최상위에 올립니다.
2. Commit changes로 저장합니다.
3. Render → Manual Deploy → Deploy latest commit을 실행합니다.
4. Live가 되면 진행자/청취자 화면을 새로고침하고 같은 임의의 코드로 입장합니다.

주소 /host, /listen은 그대로입니다. 음성은 계속 LiveKit SFU를 사용합니다.
기존 Render의 ROOM_CODE/HOST_PIN은 남겨두어도 새 버전에서 사용하지 않습니다.
LiveKit 키, SESSION_SECRET, DATA_DIR, Node 버전, 빌드/시작 명령은 변경하지 않습니다.
이 ZIP은 이미 배포된 V6에 덮어쓰는 수정 파일입니다.
이전 비밀번호 제거 ZIP을 따로 먼저 적용할 필요는 없습니다.
이전 README/배포안내의 고정 ROOM_CODE와 HOST_PIN 설명은 이 수정본에서는 해당되지 않습니다.

검증: 서버 테스트 9개 통과, 서로 다른 방의 질문 접근/답변 변경 차단,
같은 코드의 SFU 방 일치와 다른 코드의 SFU 방 분리, 재시작 후 방별 인증/질문 복원,
고정 ROOM_CODE 설정 없는 모바일 진행자 입장 검증 통과.
실제 배포와 음성 확인은 재배포 후 실시합니다.
