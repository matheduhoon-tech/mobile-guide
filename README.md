# 죽산중고등학교 IB 모바일 무선가이드 V6

이 ZIP은 기존 GitHub + Render 서비스를 교체하는 완성 소스입니다. 음성은 별도의 LiveKit SFU로 전송합니다. 진행자마다 마이크 트랙을 한 개씩 송출하며, 청취자 수에 따라 진행자 송출 연결을 늘리지 않습니다.

처음 적용할 때는 **배포안내.md**를 순서대로 따라 하세요. 행사 전 확인 항목은 **현장시험표.md**, 이번 검증 범위는 **검증결과.md**에 있습니다.

| 담당 | 기능 |
| --- | --- |
| GitHub | 배포 소스와 버전 관리 |
| Render Node Web Service | `/host`, `/listen`, 학교 로고, 입장 인증, LiveKit 토큰 발급, 질문 접수와 조회 |
| Render 영구 디스크 | SQLite 질문/답변 상태 저장; 최근 24시간만 보관 |
| LiveKit Cloud | SFU 음성 중계, 여러 마이크 트랙 분배, WebRTC 연결 복구와 네트워크 우회 |

진행자 → LiveKit SFU → 청취자 30명 이상. 두 진행자가 동시에 방송하면 청취자마다 두 음성을 동시에 재생합니다. 늦게 방송을 시작한 진행자의 트랙도 자동 구독합니다. 진행자는 다른 진행자의 음성을 구독하지 않으며, 청취자는 마이크/카메라 송출 권한이 없습니다.

유지 기능: 역할별 주소, 입장 코드, 죽산중고등학교 로고와 IB 표시, 질문 전송/목록, 자동 재연결, 화면 꺼짐 방지. 추가 기능: 진행자 PIN, 질문 전송 확인과 중복 방지, 진행자 간 공유되는 답변 완료 상태, 영구 디스크 사용 시 질문 복원, 청취자 화면 꺼짐 방지.

## 파일 구성

- `server.js`: 인증, SFU 권한과 토큰, 질문 API/SQLite
- `public/index.html`, `public/school-logo.png`: 기존 디자인과 학교 로고
- `src/app.js`: 브라우저 기능 원본
- `public/app.js`: 빌드된 LiveKit 포함 브라우저 파일; 별도 CDN 의존 없음
- `build.cjs`: 브라우저 파일 빌드
- `package.json`, `pnpm-lock.yaml`, `pnpm-workspace.yaml`: 버전 고정 설치
- `render.yaml`: 새 서비스용 유료 Starter + 디스크 구성 예시
- `.env.example`: 설정 이름 예시; 실제 비밀값을 넣어 GitHub에 올리지 마세요
- `test/server.test.cjs`: 서버 기능 검증

Node 24.13 이상 25 미만, pnpm 11.25.0을 사용합니다. 권장 Node 버전은 24.19.0입니다. 로컬 확인: `.env.example`을 `.env`로 복사한 뒤 실제 값을 입력하고, `corepack enable`, `pnpm install --frozen-lockfile`, `pnpm build`, `pnpm test`, `pnpm start`를 실행하세요. 브라우저에서 `http://localhost:3000/host` 또는 `/listen`을 여세요. localhost 외 휴대폰 접속에는 HTTPS가 필요합니다.

## 운영 범위

현재 구성은 방 하나와 Render 인스턴스 하나를 대상으로 합니다. 같은 ROOM_CODE를 입력한 진행자·청취자가 한 방에 모입니다. 입장 코드는 영문/숫자 1~8자, 대소문자를 구분하지 않습니다. 진행자는 PIN을 추가 입력합니다.

입장 인증은 12시간, 새 SFU 토큰은 15분 동안 유효합니다. SDK 연결 복구가 실패하면 새 토큰을 받아 1~30초 간격으로 재시도합니다. 입장 인증 만료 또는 관리자에 의한 퇴장/방 삭제 시에는 다시 입장합니다. SFU 토큰 재발급 시 참가자 ID를 유지합니다. 네트워크 복구 후 방송이 자동으로 복원되지만 OS가 마이크 권한/캡처를 중단한 경우 방송 시작 버튼을 다시 눌러야 합니다.

질문은 서버 확인을 받은 후 입력창을 비웁니다. 실패 후 같은 질문을 재전송하면 같은 ID를 사용해 중복 접수를 막습니다. 각 청취자는 분당 12개, 방 전체는 최근 24시간 2,000개까지 접수합니다. 모든 진행자는 3초마다 같은 목록/답변 상태를 확인합니다. 질문 보관은 24시간이며, 이 저장 방식은 장기 기록 보관용이 아닙니다.

실제 30대 음성 품질은 LiveKit 프로젝트 동시 접속 한도, 휴대폰/학교 Wi-Fi 상태, 통신망, 화면 잠금 정책에 영향을 받습니다. SFU 구조만으로 끊김 없는 현장 운용을 보장하지 않습니다. 배포 후 현장시험표를 완료하세요.
